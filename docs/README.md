# 문서 목차

| 문서 | 누가 읽나 | 내용 |
|---|---|---|
| [발표자 가이드](presenter-guide.md) | 최종 발표자 | 핵심 메시지, 시연 순서, 외워 둘 숫자, 제안서에서 달라진 점, 예상 질문과 답 |
| [구조와 모듈](architecture.md) | 코드를 보거나 고칠 사람 | 파일별 역할(M1~M4), 화면 구성, 핵심 규칙(성향 → 위치, 근사값, 미래 정보 미사용), 데이터 파일 |
